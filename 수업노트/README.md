# 수업노트

수업 녹음을 클로드 앱(claude.ai)에서 요약받은 뒤, 그 요약을 여기(Claude Code 채팅)에 붙여넣으면
망고가 과목/주제별 파일로 정리해서 저장해주는 공간.

## 사용법

1. 수업을 폰 녹음앱으로 녹음
2. claude.ai 앱에 녹음 파일을 올려서 요약 받기
3. 나온 요약을 이 프로젝트 채팅에 붙여넣고 "정리해서 저장해줘"라고 요청
4. 망고가 과목명으로 파일(`과목명.md`)을 만들거나, 기존 파일에 해당 날짜 항목을 추가

## 파일 구성

- 과목/주제 하나당 파일 하나 (`예: 축로기술.md`, `열분해로.md`)
- 각 파일 안에서는 최신 수업이 맨 위에 오도록 날짜순 기록 (형식은 위스키체크의 LOG.md와 동일한 방식)
