# 여행지수

## Overview
사용자가 지정한 여행지 + 시기에 대해, 그 시점 기준으로 실시간 조사해서
"지금 가기 좋은 정도"를 0~100점으로 채점하고 리포트(Artifact)로 만드는 반복 작업.
카에루몰/항공권체크와 같은 패턴 — 별도 서버 없이 물어볼 때마다 그때그때 조사.

## 입력
- **여행지**: 전 세계 자유 입력 (도시/국가 무관하게 받음)
- **시기**: 월 또는 날짜 범위. 안 주어지면 먼저 물어볼 것 — 임의로 정하지 말 것.
- **출발지**: 명시 안 하면 부산(김해공항, PUS) 기준으로 항공권 조사 (사용자의 기본 출발지).

## 점수 구성 (6개 요소, 가중치 고정)

| 요소 | 비중 | 판단 기준 |
|---|---|---|
| 항공권 가격 | 20% | 해당 노선/시기 가격을 "평소 대비"로 채점 |
| 성수기/혼잡도 | 20% | 그 시기가 해당 여행지의 성수기인지 비수기인지 |
| 환율 | 20% | 원화 기준으로 그 통화가 최근 대비 싼지 비싼지 |
| 날씨 | 15% | 강수 확률/맑은 날 비율 등 컨디션 |
| 기온 | 15% | 쾌적 온도대(18~26도)에 가까울수록 고득점 |
| 호텔 가격 | 10% | 해당 시기 숙박비를 "평소 대비"로 채점 |

가중치 합 100%, 절대 임의로 바꾸지 말 것 (사용자가 다시 지정하지 않는 한).

## 요소별 조사 방법 및 0~100 환산

1. **항공권 가격 (20%)**: Google Flights(브라우저 자동화, mcp__claude-in-chrome)로 실시간 조회.
   Google이 직접 표시하는 "가격이 현재 저렴합니다 / 보통입니다 / 비쌉니다" 배지와 "평소보다 얼마 저렴/비쌈" 문구를 그대로 활용.
   - 저렴함 → 75~100점 (저렴한 정도에 비례)
   - 보통 → 45~70점
   - 비쌈 → 0~40점

2. **성수기/혼잡도 (20%)**: 웹검색으로 "OO 여행 성수기/비수기", "OO 최고 여행 시기" 등 조사.
   - 명백한 비수기 → 80~100점
   - 어중간한 시기(중간 성수기) → 40~70점
   - 명백한 성수기(연휴/여름휴가철/현지 축제 등) → 0~35점

3. **환율 (20%)**: 웹검색으로 현재 환율과 최근 6개월~1년 평균/범위 비교.
   - 최근 평균보다 원화가 강세(그 통화가 쌈) → 70~100점
   - 평균과 비슷 → 40~65점
   - 원화가 약세(그 통화가 비쌈) → 0~35점

4. **날씨 (15%)**: 웹검색으로 해당 시기 평년 기후(강수 확률, 맑은 날 비율) 조사.
   임박한 여행(1~2주 이내)이면 실제 예보도 함께 반영.
   - 강수 확률 낮고 맑은 날 많음 → 70~100점
   - 우기/장마철 등 강수 확률 높음 → 0~40점

5. **기온 (15%)**: 웹검색으로 해당 시기 평균 최고/최저 기온 조사.
   18~26도 범위에 가까울수록 고득점, 폭염(33도↑)이나 혹한(0도↓)에 가까울수록 감점.
   활동 목적(스키 여행 등 저온이 오히려 목적인 경우)은 사용자가 명시하면 예외 적용.

6. **호텔 가격 (10%)**: 부킹닷컴/아고다 등을 브라우저 자동화로 실시간 조회, 평소 대비 저렴도 판단.
   구체적 숙소가 없으면 해당 도시 평균 숙박비 시세로 대체 조사.

## 총점 계산
각 요소 0~100점 × 가중치 → 합산 = 최종 0~100점.

## 등급 구간 (2026-08-21 확정, 임의로 바꾸지 말 것)

| 총점 | 등급 |
|---|---|
| 80~100 | 최적기 — 지금 가세요 |
| 65~79 | 좋음 — 가기 좋은 시기 |
| 50~64 | 보통 — 나쁘지 않지만 최적은 아님 |
| 35~49 | 비추천 — 다른 시기 고려 |
| 0~34 | 최악 — 피하는 게 좋음 |

## 리포트 작성
- 총점을 맨 위에 크게 표시
- 요소별 세부 점수를 막대/배지로 시각화
- "지금 가면 좋은 이유" / "아쉬운 점"을 1~2문장씩 정리
- Artifact로 게시 (claude.ai에서 공유 가능한 웹페이지)

## 결과 기록

CLAUDE.md의 "Notion 작업 로그" 절 참고). 프로젝트 속성은 "여행지수"로 남길 것.
