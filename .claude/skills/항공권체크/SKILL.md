# 항공권 체크

## Overview
부산(김해공항, PUS)을 한국 측 기준 공항으로 고정하고, 지정된 노선의 항공권 가격을 찾는 반복 작업.

## 고정 규칙 (사용자 지시, 2026-08-21)

1. **한국 측 공항은 무조건 부산(김해공항, PUS)**. 인천/김포 등 다른 공항은 고려하지 않는다.

2. **여행 기간은 사용자가 매번 직접 지정한다.** 날짜 없이 "체크해줘"라고만 하면 먼저 날짜부터 물어볼 것 — 임의로 기간을 정해서 진행하지 말 것.

3. **대만(타오위안, TPE) 노선**:
   - **부산 → 타오위안(가는 편)**: 무조건 **대한항공**만 검색. 다른 항공사 대안을 제시하지 않는다.
   - **타오위안 → 부산(오는 편)**: **에어부산**을 확인하고, 그 외에 **가장 저렴한 항공편 2개**를 추가로 찾아 총 3개(에어부산 + 최저가 2개)를 제시한다.
     - 에어부산이 이미 최저가 2개 안에 들면 중복으로 세지 말고, 최저가 2개 + 에어부산(있으면 별도 표시)으로 정리.

4. **일본 노선 (부산 출발, 고정 대상 도시 4곳: 후쿠오카·오사카·도쿄·삿포로)**:
   - 사용자가 특정 도시만 콕 집어 말하지 않는 한 4개 도시 전부 확인한다.
   - 항공사 제한 없음 — **순수 최저가 기준**.
   - **왕복 최저가**를 먼저 찾고, **편도+편도 조합**(다른 항공사·다른 날짜 조합 포함)으로 왕복보다 더 싼 조합이 있으면 그것도 비교해서 최종적으로 가장 저렴한 방법을 제시한다.

## 검색 방법
항공권 가격은 매일 바뀌고 날짜에 따라 달라지므로, WebSearch로는 정확한 실시간 가격을 못 얻는다.
Google Flights(https://www.google.com/travel/flights) 등을 브라우저 자동화(mcp__claude-in-chrome)로
직접 열어서 사용자가 지정한 날짜로 검색해 확인할 것.

## 결과 기록
검색 결과는 Notion "작업 로그" DB에 기록한다 (인증 정보: `C:\Users\PC\.claude\notion_credentials.json`,
CLAUDE.md의 "Notion 작업 로그" 절 참고). 프로젝트 속성은 "항공권체크"로 남길 것 — 나중에
"그때 그 항공편 얼마였지" 하고 다시 찾을 수 있도록.
