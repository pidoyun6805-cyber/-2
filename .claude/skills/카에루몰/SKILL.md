# 카에루몰 위스키 체크

## Overview
카에루몰(kaerumall.com, 일본 야후옥션 구매대행)에서 지정 14개 증류소/보틀러의 경매 매물 중
"메리트 있는"(가성비 좋은) 물건을 찾아 HTML 리포트로 정리하는 반복 작업.

## 사전 조건
- Chrome 확장(mcp__claude-in-chrome)이 연결되어 있어야 함. `tabs_context_mcp`로 확인.
  연결 안 되면 사용자에게 크롬 확장 켜달라고 요청하고 멈출 것 (재시도 반복 금지).
- 카에루몰 로그인 계정: **피원호1 (piwonho1)**. 이미 로그인된 탭이 있으면 재사용, 없으면 로그인부터.
- **승인 프롬프트 없이 완전 자동 실행**되어야 함 (2026-08-09 사용자 명시 지시). 이 스킬이 쓰는 도구
  (Agent, mcp__claude-in-chrome__*, Bash(curl/node/mkdir/cp), Artifact)는 프로젝트
  `.claude/settings.json`에 전부 allow 등록되어 있음 — 실행 중 permission 프롬프트가 뜨면 그건
  설정 누락이니 멈추지 말고 필요한 권한을 settings.json에 추가한 뒤 계속 진행할 것.

## 절차

1. **관심 증류소/보틀러 (14개, 고정, 전부 동일 기준 적용 — 증류소별 예외 없음)**:
   DAFTMILL, GLENDRONACH, MACALLAN, LAPHROAIG, YAMAZAKI PUREMALT, SPRINGBANK,
   BOWMORE, GLEN GRANT, BEN NEVIS, SIGNATORY, AKKESHI, CHICHIBU, CLYNELISH, GLENFARCLAS

   **"YAMAZAKI PUREMALT" 검색어 주의 (2026-08-12 확인, 2026-08-13 재확인):** 카에루몰에서
   "YAMAZAKI PUREMALT"로 그대로 검색하면 산토리(Suntory)의 유명 정규 야마자키가 나오는데,
   이건 타겟이 아니다. 실제 타겟은 사사노가와 주조(笹の川酒造)의 **"YAMAZAKURA(야마자쿠라)
   퓨어몰트"**다 — 검색어를 "YAMAZAKURA"로 바꿔서 진행할 것. 2026-08-13 조사에서 이 보정을
   빠뜨리고 다시 산토리 야마자키로 검색한 사례가 있었음 — 매 실행마다 이 문단을 반드시 확인.

2. **병렬 조사**: 절대 순차로 하지 말 것. 14개를 3~5개 그룹으로 나눠 background Agent(general-purpose)
   여러 개를 동시에 띄운다. 각 에이전트는 부모가 로그인해둔 크롬을 공유하되 반드시 자기 전용 새 탭
   (`tabs_create_mcp`)을 만들어 쓴다 — 기존 탭 건드리지 말 것.

3. **각 에이전트가 할 일** (증류소별로):
   - 카에루몰에서 검색어로 검색, **결과 페이지는 무조건 최대 2페이지까지만 확인 — 예외 없음.**
     건수가 아무리 많아도, 검색결과가 총 몇 페이지든(3페이지짜리든 6페이지짜리든) 2페이지까지 보고
     멈춘다. "전수 확인"한다고 3페이지 이상 넘어가지 말 것 (2026-08-09 라프로이그 3페이지 확인
     사례처럼 지시 위반하지 말 것 — 페이지 총량과 무관하게 하드캡 2).
   - **가격 기준: 현재가 53,000엔(≈400달러 면세 한도) 초과는 무조건 제외 — 예외 없음.**
      붙어서 메리트가 사라지기 때문 — 아무리 희귀해도 53,000엔 넘으면 쳐다보지 말 것.)
     입찰수 **5건 이상**이면 "고입찰"로 별도 표시하되, 이것도 53,000엔 상한 자체를 면제해주는
     게 아님 — 고입찰 표시는 어디까지나 53,000엔 이하인 항목 중에서의 부가 태그.
   - **한 증류소당 후보를 1개로 제한하지 말 것.** 기준(5번)을 통과하는 병이 여러 개면 전부 후보에
     올린다. 단, 최종 보고에는 아래 "사용량 절감" 규칙에 따라 상위 후보만 추려서 낸다.
   - 미니어처(50ml 등)/빈병/빈상자/여러 병 섞인 세트상품은 목록엔 남기되 WhiskyBase 개별 조회는 생략
   - 병 사진 URL도 같이 수집 (아래 "이미지 수집" 참고)
   - **경매 종료까지 남은 시간도 함께 수집** (2026-08-10 사용자 요청). 상품 목록/상세 페이지에 표시되는
     "残り時間"(잔여시간) 값을 그대로 기록. 최종 보고 표에도 이 값을 컬럼으로 포함할 것.

   **사용량 절감 원칙 (2026-08-09 저녁 개정 — 이번 조사가 이전보다 토큰을 훨씬 많이 써서 추가)**:
   - **1차 필터는 제목만 보고 기계적으로.** 목록 페이지를 훑을 때 상품명에 "12년/10년/15년
     오리지널", "Double/Triple Cask", "Select Oak", "Fine Oak" 등 흔한 정규품 키워드가 보이면
     깊이 판단하지 말고 바로 제외한다. 애매한 것(빈티지/캐스크번호/한정판 표기가 있는 것)만
     개별적으로 더 살펴본다 — 상품 하나하나를 전부 정독하며 판단하지 말 것.
   - **WhiskyBase 개별 조회는 최종 후보로 남을 가능성이 높은 것에만.** 조회 URL:
     `https://www.whiskybase.com/search?q=<검색어>&entity=bottles&sort_order=relevance&page=1&page_size=100`
     (get_page_text로 결과 테이블 파싱). 후보군 전체를 하나씩 조회하지 말고, 먼저 브랜드/보틀러/
     빈티지 단위로 1~2회 검색해서 "이 라인업은 대략 몇 점대"감을 잡은 뒤, 84점 경계에 걸쳐 있어
     확실히 판단해야 하는 것만 개별 재조회한다.
   - **WhiskyBase 평점을 확인할 때는 점수와 함께 평점을 매긴 인원수(참가자 수)도 같이 기록**
     (2026-08-10 사용자 요청). 표기 형식: `WB 86.54 (314평점)`. 인원수를 못 구했으면 점수만
     표기하고 "(인원수 미확인)"으로 남길 것.
   - **증류소당 최종 보고 후보는 최대 5~6개로 추려서 낸다.** 리포트 전체 목표가 약 50개(14개
     증류소 평균 3.5개, 2026-08-13 사용자 요청으로 기존 35개에서 상향)이므로, 발견한 후보를
     전부 표로 나열하지 말고 이미 상위권으로 추려서 보고할 것. "찾은 걸 다 보여달라"는 요청이
     아니라 "메리트 있는 상위 후보"를 원하는 것임.
   - **최종 응답에 표 전체를 반드시 포함할 것.** 요약 문장만 먼저 보내고 표는 "위에 있다"는 식으로
     생략했다가 재요청받는 왕복이 실제로 발생했음 — 한 번에 완결된 응답을 낼 것.

## 자동화 제약
카에루몰/WhiskyBase 둘 다 JS 렌더링 사이트라 클라우드 루틴에서 curl/WebFetch로 접근 불가
(카에루몰은 빈 SPA만 반환, WhiskyBase는 자동요청 403 차단). 실제 검색은 **로컬 세션 + 크롬 확장**
으로만 가능. 클라우드 루틴("카에루몰 위스키 체크 리마인더", trig_01K7fa8nKEYjsc7mbK2R5azB)은
홀수 날짜 저녁 8시(KST)에 푸시 알림만 보내고, 실제 체크는 이 스킬로 로컬에서 수행.
