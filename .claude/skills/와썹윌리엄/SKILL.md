# 와썹윌리엄

## Overview

피도윤이 구독한 네이버 프리미엄 채널 "와썹윌리엄"의 전체 글 858개를 근거로,
시장·섹터·종목·경제상황 질문에 답한다.

**핵심 원칙: 윌리엄은 종목을 찍지 않지만, 이 스킬은 찍는다.**
윌리엄의 글은 판단 기준이고, 그 기준을 실제 기업에 대입해 이름을 대는 것이 이 스킬의 일이다.
"윌리엄이 종목을 언급하지 않았다"는 답변을 회피할 이유가 되지 않는다.

**858개를 다 읽지 말 것.** `search.js`로 관련 글만 찾아 읽는다.

```bash
cd "C:\Users\PC\Desktop\도윤 클로드\.claude\skills\와썹윌리엄"
node search.js "변압기 전력"      # 키워드 검색 (관련도순, 발췌 포함)
```

읽는 순서: 검색 → 상위 5~10개 글 본문 읽기 → 부족하면 인접 시리즈 추가.
질문이 최근 시장에 관한 것이면 `-r 30`으로 최근 글을 먼저 훑는다.

## 두 가지 모드

### 모드 A: 섹터·종목 질문
"반도체 어때?", "무슨 주식이 좋아?", "AI 관련해서 뭘 봐야 해?"

1. `search.js`로 해당 산업 글을 찾아 읽는다. `reference/병목지도.md`를 먼저 보면 어느 글을 읽을지 빨라진다.
2. 그가 지목한 **병목**을 확정한다. 산업 이름이 아니라 "그 산업이 우회할 수 없는 자리"다.
3. **웹 검색으로 그 자리에 실제로 앉은 기업과 최신 수치를 확인한다.** 리드타임, 수주잔고, 점유율, 최근 분기 실적 같은 검증 가능한 숫자를 가져온다. 국내 기업도 함께 찾는다.
4. `reference/체크리스트-용어.md`의 20개 항목으로 후보를 거른다.
5. **선점 여부를 판정한다.** 그의 원칙상 대중이 이미 몰린 자리는 늦은 진입이다. 증권가가 이미 떠드는 자리인지, 아직 조용한지 구분해서 말한다.

### 모드 B: 경제상황 브리핑
"지금 경제상황 어때?", "시장 어떻게 봐?"

1. `reference/지표.md`에서 그가 보라고 한 지표 목록을 확인한다.
2. **웹 검색으로 각 지표의 현재 값을 조회한다.**
3. 그의 해석 틀에 대입해 국면을 판정한다.
4. 최근 30일 글을 훑어 그가 지금 무엇을 경고하고 무엇을 준비하라 했는지 반영한다.

## 답변 형식 (필수 구성)

답변은 아래 네 부분으로 이뤄진다. 순서대로 낸다.

**1. 결론** — 한 문단. 질문에 대한 직접적인 답.

**2. 윌리엄의 근거** — 그가 지목한 병목과 그가 만든 조어. 각 항목에 출처 글 제목과 날짜를 병기한다.

**3. 실제 기업** — 표로 낸다. 최소 3개, 국내외를 함께 담는다.

| 구분 | 기업 | 그 자리에서의 위치 | 최신 수치 |
|---|---|---|---|

수치는 웹에서 확인한 것만 쓴다. 확인 못 한 항목은 빈칸으로 두고 그렇다고 적는다.

**4. 선점 여부** — 이미 붐빈 자리인지, 아직 조용한지. 그의 "대중이 달려들 때 금융부자는 다음 공간에 있다"를 적용한 판정.

마지막에 참고한 웹 출처를 마크다운 링크 목록으로 붙인다.

## 윌리엄의 핵심 논리

한 문장이다.

> 대중은 뜨는 산업을 사기에 늘 뒤늦게 실패하고,
> 금융부자는 그 산업이 반드시 의존할 병목을 사기에 가장 안전한 미래를 선점한다.

그래서 그는 산업 이름 대신 매번 "그 산업이 어디서 멈추는가"를 찾고 거기에 이름을 붙인다.
`reference/병목지도.md`에 산업별 병목과 조어가 정리돼 있다.

대장주 선별은 20개 체크리스트로 하고, 16개 이상이면 투자한다고 했다.
상세 판별법은 `reference/체크리스트-용어.md`에 있다.

## 아카이브 갱신

윌리엄은 주 12회쯤 올린다. 마지막 수집일에서 시간이 꽤 지났으면 먼저 갱신한다.

전용 크롬을 띄운다. 크롬 확장은 naver.com을 차단하므로 이 방식만 된다.

```bash
"C:\Program Files\Google\Chrome\Application\chrome.exe" \
  --user-data-dir="C:\Users\PC\.claude\chrome-naver-profile" \
  --remote-debugging-port=9222 --no-first-run --no-default-browser-check
```

그다음 갱신한다.

```bash
cd "C:\Users\PC\Desktop\도윤 클로드\와썹윌리엄"
node update.js
```

봇차단 방지 정책이 스크립트에 내장돼 있다. 순차 1건씩, 7~12초 간격, 이상 감지 시 자동 감속.
**병렬로 돌리지 말 것.** 같은 계정에서 동시 요청이 나가는 게 봇 판정의 가장 명확한 신호다.

## 경계

투자 자문사가 아니다. 윌리엄의 논리를 실제 기업에 대입한 분석을 제공하는 것이지,
사용자의 재무 상황에 맞춘 권유가 아니다. 답변 끝에 한 줄로만 짚고 넘어간다. 반복하거나 훈계하지 않는다.
