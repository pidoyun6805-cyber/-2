# 거시경제 지표 프레임워크

와썹윌리엄 아카이브에서 추출. 모든 항목에 출처 글과 날짜를 병기했다.
경제상황 브리핑(모드 B)의 재료다. **여기 적힌 기준만 쓴다. 새 기준을 만들지 않는다.**

## 대전제

> "대중은 결과를 보고 금융부자는 구조를 본다" — 비밀지표 프롤로그 (2025-12-30)
> "은행은 가격을 움직이기 전에 태도를 바꾼다. 주가는 나중 문제고 부동산은 더 나중, 실물은 맨 마지막" — 비밀지표 1편 (2026-01-03)
> "진짜 위기는 돈이 부족할 때보다 담보가 믿음을 잃을 때 훨씬 빠르게 번진다" — 진정한 월가의 금융부자들이 (2026-09-03)

지표는 예측용이 아니라 **이미 내부에서 시작된 변화의 확인용**.
방향·기울기·지속성만 본다. 절대 수치 판단, 과거 위기와 직접 비교, 시점 예측은 그가 금지했다.

## 1. 월가가 뉴스보다 먼저 보는 8가지

출처: 「진정한 월가의 금융부자들이! 경제 뉴스가 나가기 한참 전 부터 먼저 알고 보는 것들」(2026-09-03)

| 지표 | 그가 설명한 의미 | 신호 해석 |
|---|---|---|
| Repo Rate | 주식보다 먼저 돈 빌리는 비용을 보는 것 | "Repo가 흔들리기 시작하면 가격보다 먼저 금융 배관에서 이상 신호" |
| Treasury Basis | 국채 현물·선물 가격차. "몇 bp처럼 보여도 여기에 거대한 레버리지가 올라가" | "역방향으로 풀리는 순간 시장은 갑자기 폭력적으로 변한다" |
| Primary Dealer Balance Sheet | 발행량이 아니라 흡수 능력 | "공급보다 흡수 능력이 중요" |
| Dealer Financing | 무엇을 샀냐가 아니라 무슨 돈으로 들고 있느냐 | "위험한 순간은 좋은 자산조차 들고 있을 자금이 없어지는 순간" |
| CFTC TFF Positioning | Dealer / Asset Manager / Leveraged Fund 중 누가 몰렸는지 | "포지션보다 포지션의 주인이 누구인지가 더 중요" |
| Treasury Auction Tail | 낙찰금리가 아니라 시장 예상과 실제 결과의 괴리 폭 | "시장이 미국 정부 부채를 얼마나 적극적으로 받아들이는지" |
| Swap Spread | Swap과 Treasury의 차이 | "딜러 밸런스시트·채권공급·헤지수요·자금조달 압력이 한꺼번에" |
| Collateral | "자본주의는 담보로 돌아간다. 신용과 담보는 결혼한 부부" | 담보 신뢰 붕괴가 가장 빠른 전염 |

그의 4대 질문: 누가 돈을 빌렸나 / 무엇을 담보로 잡았나 / 누가 반대편에 서 있나 / **누가 가장 먼저 강제로 팔아야 하나**

## 5. 경제 국면 분류

### 5-A. 위기 진행 12단계 (비밀지표 시리즈의 정본 순서)

> "태도 → 선택 → 전염 → 차단" (4-1편)

| 단계 | 무엇이 일어나는가 | 지표 |
|---|---|---|
| 1 | 은행이 움직이기를 멈춤 (태도) | WRESBAL 속도 |
| 2 | 은행이 서로를 포기 (행동) | SOFR–IORB |
| 3 | 국경 넘어 달러 조달 선별 (전염) | Cross Currency Basis |
| 4 | 대출 기준 차단 | SLOOS |
| 5~6 | 정리 대상 결정(첫 후보 CRE), 기업 꼬리 두꺼워짐 | DRCRELEXFACBS, A053RC1Q027SBEA |
| 7 | 자금이 대기 | MMFSL |
| 8 | 국가가 개입 (자율→관리 시스템) | TGA |
| 9 | 완충 장치가 얇아짐 | Primary Dealer Net Position |
| 10 | 공포 달러 | DTWEXBGS 조합 |
| 11 | 물건 자체가 멈춤 | LC |
| 12 | 국가 신뢰 재평가 | CDS vs 환율 괴리 |

### 5-B. 유동성 사이클

QT → 준비금 소진 → 은행 간 신뢰 위축 → 리포 경색 → 연준 개입(비공식 QE) → 정책 전환 3단계(리포 공급 증가 → T-bill 발행↑·수익률↓ → FOMC 공식 발표) → QE 재개 → 신용 팽창 → 거품 → 위기 → 반복

> "QT의 마지막 단계는 언제나 리포 폭증이었고, 그 직후엔 항상 QE 재개" (4편)
> "연준이 움직였다는 건 이미 늦었다는 뜻" (4편)

## 7. 반복되는 인과 사슬

**담보-레버리지** (2026-09-03): 좋은 담보 → 차입 → 레버리지 → 가격 상승. 역방향은 담보 신뢰 붕괴 → 강제 매도 → 약한 고리 순서대로 붕괴.

**유동성 배관** (네프콘 1~5편): QT → 준비금 감소 → 은행 간 불신 → 현금 보유 경쟁 → Repo 급등 → 연준 투입 → 시장 대 연준으로 전환 → QT 중단 → QE 재개 → 신용팽창 → 거품 → 위기

**파이프라인 3단** (5편): MMF가 RRP에서 인출 → 리포시장 → 프라임브로커 → 프라이머리 딜러 → 최종 종착지 연준 계정

**유동성 3레이어** (3편): 대중이 보는 유동성 / 금융권이 보는 유동성 / 금융패권자가 움직이는 유동성

**금리 → 주식** (2025-07-30): 금리↑ → 차입비용↑ → 위험자산 팔아 빚 갚고 안전자산 이동 + 미래이익 현재가치 급락 → 주가↓

**환율** (2025-07-26/27): 연준 인상 → DXY↑ → 원화 상대가치↓ → 원달러↑ → 수입물가↑. 2008년 900원→1,500원

**미국 패권 흡수** (2025-08-22 / 09-23 / 09-25): 관세 → 상대국 수출 타격 → 절하·금리인하 → 자본 유출 → 미국으로 유입 → 달러 강세. 타국 4갈래 딜레마: 금리 방어→내수 붕괴 / 금리 인하→외환위기 / 환율 방어→보유액 고갈 / 환율 방치→수출 붕괴. 스테이블코인 → 1:1 준비금 의무 → 국채 수요 영구 락인

**국채발 충격 전이** (2026-04-10): 국채 입찰 부진 → 장기금리↑ → 할인율↑ → ①나스닥 고밸류 성장주 → ②basis trade 강제 청산 → ③CRE·중소은행 → ④주택·모기지 → 소비

**금융 → 실물** (11편, 2026-02-26): 금융 수축 → 보증(LC) 축소 → 실물 정지 → 원자재 주문↓ → 운송계약↓ → 중간재↓ → 고용 둔화

**한국 내부 악순환** (2025-12-02): 원화 약세 → 수입 원자재·에너지↑ → 물가 압박 → 금리·정책 제약 → 외국인 이탈 → 환율 추가 상승(정상 회귀가 아니라 추세 가속). 가계부채 + 국민자산 70% 부동산 → 부동산 붕괴 → 가계 붕괴 → 은행 붕괴

**자본의 3레이어** (2025-10-15): 기반층 Infra(에너지·데이터·전력망) → 유통층 Flow(결제·통화·블록체인) → 표면층 Value(소비·기술). "자본은 아래층에 더 오래 머문다"
